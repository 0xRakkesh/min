## 1. High-Level URL Shortener Architecture
A service like Bitly handles two primary paths:

```
Write Path (Shortening):
Client (POST /shorten with target_url)
    └──▶ Server generates unique Short ID (e.g. Base62)
         └──▶ Saves mapping: Short ID ↔ Long URL in storage
              └──▶ Returns short URL to client

Read Path (Redirection):
User clicks short link (GET /{short_id})
    └──▶ Server looks up Short ID in storage (O(1) HashMap)
         └──▶ Server responds with HTTP 307 Temporary Redirect + Location header
              └──▶ Browser automatically navigates to destination URL
```

## 2. Key FastAPI & Python Concepts

### Decorators (`@app.get`, `@app.post`)
- **What they are:** Syntactic sugar in Python that wraps a function to extend or register its behavior without changing its source code.
- **Behind the scenes:**
  ```python
  @app.get("/")
  def root(): ...
  # is equivalent to:
  root = app.get("/")(root)
  ```
- **In FastAPI:** Registers the function into FastAPI’s routing table with HTTP method, path, response codes, and serialization metadata.

### Request Validation with Pydantic
- **Client vs. Server Responsibility:** The client only sends the payload it knows (`target_url`). The server is the authority that generates and assigns the unique identifier.
- **BaseModel:** Validates data types, enforces required fields, and provides clean Python object access (`url_data.target_url`).

## 3. Storage Layer: Trade-offs
- **In-Memory HashMap (`dict` in Python):**
  - **Pros:** Instant average $O(1)$ read and write performance.
  - **Cons:** Volatile (cleared upon process restart). Perfect for rapid prototyping before attaching SQLite/PostgreSQL.

## 4. ID Generation: Counter + Base62 Encoding

### Why Base62?
- Uses URL-safe alphanumeric characters: `0-9` (10) + `a-z` (26) + `A-Z` (26) = **62 symbols**.
- Extremely compact: $62^6 \approx 56.8 \text{ billion}$ combinations with just 6 characters.
- **Zero collisions:** Guaranteed uniqueness when paired with an auto-incrementing integer ID (`1, 2, 3...`).

### Conversion Algorithm (Base 10 Integer ➔ Base62 String)
1. **Character Map:**
   ```
   "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
   ```
2. **Base Case:** If `num == 0`, return `"0"`.
3. **Loop:** While `num > 0`:
   - Compute remainder: `rem = num % 62`
   - Map remainder to character: `char = BASE62[rem]`
   - Prepend `char` to result string.
   - Update integer division: `num = num // 62`
